# Car Dealership Application - Fullstack Capstone Project

**Repository Name:** `xrwvm-fullstack_developer_capstone`  
**Project Name:** Car Dealership Web Application  
**Developer:** Kishore  

## Project Overview
This project is a full-stack web application developed for **Cars Dealership**, a national car retailer in the United States. The platform enables users to browse dealership branches across all states, view customer reviews with sentiment analysis, filter dealers by location, and register/login to submit reviews.

## Architecture & Technologies
- **Frontend:** React.js, Bootstrap 5, HTML5/CSS3
- **Backend Framework:** Django, Django REST Framework
- **Microservices:**
  - Node.js / Express backend for Dealership & Review database (MongoDB)
  - Python / Flask backend for IBM Watson Sentiment Analysis
- **Database:** SQLite (Django Car Make/Model data), MongoDB (Dealerships and Reviews)
- **Deployment & DevOps:** Docker containers, Kubernetes, IBM Cloud Code Engine, GitHub Actions CI/CD
